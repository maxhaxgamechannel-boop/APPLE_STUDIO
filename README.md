# APPLE STUDIO

Премиальный интернет-магазин техники Apple с интерактивными процедурными 3D-моделями.
Демонстрационный проект: не является официальным магазином Apple Inc.

**Стек:** React 19 · Vite 7 · TypeScript · Tailwind CSS 4 · Three.js · React Three Fiber · Drei · Framer Motion · GSAP · Zustand · React Router 7

## Что нового в версии 1.1

- **Главный экран без перекрытий.** Текст и 3D-сцена теперь занимают разные области сетки, поэтому надписи не закрывают iPhone ни на одном размере экрана. Подпись и кнопка повтора стоят под сценой.
- **Анимация по клику, а не по прокрутке.** При заходе автоматически проигрывается вылет iPhone из глубины. Нажатие на телефон или на кнопку под ним показывает заднюю панель, боковую грань и снова экран; нажимать можно сколько угодно раз. Прокрутка моделями больше не управляет.
- **Клик по моделям по всему сайту.** Карточки товаров, плитки экосистемы, линейка Pro и страница товара по нажатию на модель делают оборот на 360°. iPhone Duo раскрывается и складывается по нажатию. Переход на страницу товара — по названию и остальной части карточки.
- **Светлая и тёмная темы.** Переключатель в шапке и в мобильном меню. Выбор сохраняется, тема применяется ещё до отрисовки, без «вспышки». Переход плавный (View Transitions API, с запасным вариантом). Работает на всех страницах, включая каталог, корзину и оформление заказа.
- **Улучшенный iPhone.** Пропорции ближе к реальным, полированная фаска рамки, аддитивный блик защитного стекла, тонкие рамки экрана, глянцевый Dynamic Island, детализированные объективы (полированный ободок, концентрические грани, двухслойная линза), анизотропный металл.
- **Стабильность и производительность:**
  - превью в каталоге рисуются по требованию (`frameloop="demand"`): в покое GPU не нагружается;
  - одна общая карта окружения на все превью вместо отдельного рендера кубической карты для каждой карточки;
  - сцены главного экрана и товара ставятся на паузу, когда уходят с экрана;
  - убран дорогой материал с transmission, на слабых устройствах снижаются плотность пикселей и разрешение теней, отключаются частицы;
  - ErrorBoundary вокруг каждой страницы и каждой 3D-сцены, обработка потери WebGL-контекста: вместо пустого экрана показываются векторные иллюстрации;
  - повторная загрузка чанков при сбое сети;
  - страховка заставки: страница никогда не остаётся заблокированной;
  - исправлено затирание параметров фильтров при быстрых изменениях, подписки на стор стали точечными.

## 1. Установка зависимостей

Нужен **Node.js 20.19+ или 22.12+** (этого требует Vite 7). Проверить версию: `node -v`.

```bash
cd APPLE-STUDIO
npm install
```

## 2. Запуск сайта в режиме разработки

```bash
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173).

## 3. Сборка production-версии

```bash
npm run build      # результат — в папке dist/
npm run preview    # локальный просмотр собранной версии
npm run typecheck  # строгая проверка TypeScript (рекомендуется)
```

## 4. Публикация в интернете

Сайт — одностраничное приложение (SPA). Сервер должен отдавать `index.html` на любые пути: например, при прямом открытии `/product/iphone-duo`. Нужные настройки уже есть в проекте.

**Vercel** (файл `vercel.json` уже настроен):
1. Загрузите проект на GitHub.
2. На vercel.com: *Add New → Project* → выберите репозиторий.
3. Framework: **Vite**, Build command: `npm run build`, Output: `dist`. Нажмите *Deploy*.

**Netlify** (файл `public/_redirects` уже настроен):
1. *Add new site → Import from Git*, или перетащите папку `dist/` в Netlify Drop.
2. Build command: `npm run build`, Publish directory: `dist`.

**GitHub Pages:** поддерживает только статические файлы без правил переписывания. Для подпутей нужен `base` в `vite.config.ts` и `HashRouter` вместо `BrowserRouter` в `src/main.tsx`. Vercel и Netlify проще.

**Любой статический хостинг / nginx:** загрузите содержимое `dist/` и настройте fallback:
```nginx
location / { try_files $uri /index.html; }
```

### 3D без внешних файлов
Все модели построены процедурно средствами Three.js: экструдированные корпуса со скруглениями и фасками, металлические рамки, стекло, объективы с «просветлением», кнопки, динамики, разъёмы. Экраны рисуются на canvas, освещение собирается из Lightformer. Никаких .glb и HDR — сайт работает автономно.

### Производительность
- Все превью в каталоге рисуются в **одном** WebGL-контексте (drei `View`), невидимые не рендерятся, а кадры рисуются только по требованию.
- Страницы и 3D-модули загружаются лениво (`React.lazy`), библиотеки разбиты на чанки.
- Геометрии, материалы и текстуры кэшируются и переиспользуются.
- `AdaptiveDpr`, ограничение плотности пикселей на мобильных, меньше частиц и разрешение окружения.
- Без WebGL — векторные иллюстрации вместо 3D. `prefers-reduced-motion` отключает заставку, автоповорот и параллакс.

### Корзина
Добавление (с анимацией полёта к иконке), удаление, количество, цвет и опции, итоговая сумма. Корзина сохраняется в `localStorage` и переживает перезагрузку.

### Демо-оформление заказа
Заказ **не отправляется** на сервер и не оплачивается: это прямо сказано на странице оформления и на странице успеха. Чтобы подключить реальные заказы, замените блок в `onSubmit` (`src/pages/Checkout.tsx`) на запрос к своему API или к платёжному провайдеру (Stripe, Mollie и т. п.).

## Данные и цены

- Цены — **ориентировочные цены магазина в евро**, а не рекомендованные цены Apple. Редактируются в `src/data/products.ts`.
- Для устройств указаны только подтверждённые характеристики. iPhone 18 Pro, iPhone 18 Pro Max и iPhone Duo **не концепты**: Apple официально представила их 9 сентября 2026 года. У них указаны только данные из анонса, параметры, которые не раскрывались, не заполнены.
- Перед публикацией сверьте характеристики и цвета с официальными страницами Apple: линейка обновляется.
- Apple, iPhone, iPad, Mac, Apple Watch, AirPods — товарные знаки Apple Inc. Логотип Apple на сайте и в моделях не используется.

## Если что-то не запускается

1. `npm install` завершился с ошибкой версий: удалите `node_modules` и `package-lock.json`, обновите Node.js и повторите.
2. Ошибки типов в `npm run typecheck` не мешают `npm run dev` и `npm run build`: Vite не проверяет типы при сборке. Их можно исправлять постепенно.
3. Ошибка в консоли браузера: пришлите её текст, и её можно будет точечно исправить.
